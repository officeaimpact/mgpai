#### 2.2 Детектор `_check_cascade_slots` — Добавлен (НОВЫЙ)

**Функция:** Анализирует историю диалога и проверяет, что клиент ЯВНО указал критичные слоты.

**Проверяемые слоты:**
- Слот 3: Даты/месяц вылета (regex паттерны для дат, месяцев, праздников)
- Слот 3: Длительность (regex паттерны для ночей, дней, недель)
- Слот 4: Состав путешественников (regex паттерны для взрослых, детей, семей)

**Паттерны протестированы на 10 реальных сценариях:**
```
✅ "египет москва" → блокировка (нет дат, нет состава)
✅ "турция на неделю спб" → блокировка (нет даты, нет состава)
✅ "турция москва в апреле на неделю 2 взрослых" → пропуск (всё есть)
```

#### 2.3 Интеграция в `_dispatch_function`

**Логика:**
1. При вызове `search_tours` сначала проверяется `_check_cascade_slots`
2. Если слоты пропущены → возвращается ошибка с nudge-сообщением
3. Модель получает инструкцию спросить недостающие данные

**Пример ответа при блокировке:**
```json
{
  "status": "error",
  "error": "СИСТЕМНАЯ ОШИБКА ВАЛИДАЦИИ КАСКАДА: Клиент НЕ указал даты/месяц и длительность, состав путешественников! ОБЯЗАТЕЛЬНО спроси клиента ЯВНО: 'Когда планируете поездку и на сколько ночей?' и 'Сколько взрослых едет и будут ли с вами дети?'. НЕ вызывай search_tours пока клиент не ответит на эти вопросы!"
}
```

## РЕКОМЕНДАЦИИ ПО МОНИТОРИНГУ

### Ключевые метрики для отслеживания

1. **`promised_search_detections`** — должен стремиться к 0
   - Если > 0: модель всё ещё иногда описывает намерение вместо действия
   - Действие: анализ логов, возможное усиление промпта

2. **`cascade_incomplete_detections`** — должен стремиться к 0
   - Если > 0: модель пытается искать без всех слотов
   - Действие: анализ паттернов, возможная корректировка детектора

3. **`dateto_corrections`** — информационная метрика
   - Показывает, как часто модель неправильно интерпретирует `dateto`
   - Если высокий: возможно, нужно усилить правило в промпте

### Формула качества

```
Quality Score = 1 - (promised_search_detections + cascade_incomplete_detections) / total_messages
```

Целевое значение: > 0.99 (менее 1% проблемных ответов)
